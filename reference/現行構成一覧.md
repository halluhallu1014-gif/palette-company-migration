# 現行構成一覧

固定基準：自宅PC用`Palette.xlsm`（2026-08-02 19:11更新）と、2026-08-02 19:05前後にExcelから書き出された`frmPalette`、`frmExCollect`、`frmExPaste`。

## 起動

- Palette_Open
- ExCollect_Open
- ExPaste_Open

## データ

- zz_ExCategory：4列
- zz_ExData：12列
- zz_ExSetting：2列

## UI

- 白、グレー、紺
- Meiryo UI
- Paletteは最大8タイル、現在2タイル使用
- 収集フォームは細幅縦型
- 貼付フォームは本文Labelを5件表示
