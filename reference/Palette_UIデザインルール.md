Palette UIデザインルール（白＋グレー版）

細幅レイアウト
・主要フォーム幅：340
・Palette／小フォーム幅：180
・横並びを減らし、上から下への縦方向を基本とする
・フォーム外周余白：18～20
・セクション間余白：12～18

テーマ
・白とライトグレーを主役にし、紺の文字と線で引き締める
・水色や青い面は使用しない

フォント
・基本：Meiryo UI 9pt
・タイトル：12pt、太字
・セクション：10pt、太字

主要色
・背景：RGB(250,250,250)
・サブ背景：RGB(242,242,242)
・区切り：RGB(230,230,230)
・枠線：RGB(190,190,190)
・通常文字：RGB(70,70,70)
・見出し／締め色：RGB(34,50,84)
・選択背景：RGB(235,235,235)

ボタン
・主操作：薄いグレー背景、紺文字、太字
・補助操作：白背景、濃いグレーまたは紺文字
・終了操作：白背景、濃いグレー文字
・削除操作：白背景、少し濃いグレー文字

フォーム
・ライトグレーのヘッダー＋紺タイトル
・入力欄と候補カードは白＋グレー枠
・選択時だけ薄いグレー＋紺枠
・ヘッダーはタイトル、短い日本語説明、細い紺線で構成
・見出しは作業ブロック単位だけに使用
・未使用情報行は非表示にし、後続ブロックを上へ詰める

シート
・見出し行：ライトグレー背景＋紺文字
・データ領域：白背景＋薄いグレー罫線
・シートタブのみ小面積の紺アクセント
